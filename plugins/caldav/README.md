# 个人 CalDAV 日历

上游支持连接自建 CalDAV（设置 → 日程 → CalDAV），但**只读**。插件在这套连接之上补上：

- 在日历里新建、修改、删除日程（条件写入，防止覆盖其他设备的修改）；
- 把今天的个人日历日程并入岛体「待办」页；
- 完成状态只保存在本机，不回写日历。

## 写入

`write.rs` 复用上游的发现、认证和 ICS 解析，只补上 `PUT` / `DELETE`：

- 新建用 `If-None-Match: *`，修改用 `If-Match: <ETag>`；服务器返回 409/412 时提示
  「日程已被其他设备修改或删除，请刷新后重新编辑」；
- 服务器只给弱 ETag（`W/`）或没有 ETag 时拒绝修改，避免误覆盖；
- 重复日程（`RRULE` / `RDATE` / `RECURRENCE-ID`）和多事件对象只读；
- 修改时保留原来的地点、说明、提醒（`VALARM`）等没有编辑的字段，`SEQUENCE` 加一；
- 只向配置里的同一个来源发请求，重定向到其他域名一律拒绝，凭据不外发。

凭据按「服务器 + 用户名」隔离（`calendar::Config::credential_name`）：自建服务的用户名
区分大小写，两个不同服务器的同名账号也不会共用密码。这是插件对上游唯一的行为修正。

## 待办联动

- 每 5 分钟（以及配置或日期变化时）在后台线程拉取当天日程，界面只读快照；
- 待办页在本地待办后面追加「日历 · 标题」行：勾选只写
  `%APPDATA%/Daozai/calendar-completed.json`，点铅笔打开编辑窗口；
- 同步失败时在待办页右下角显示原因。

## 入口

- **日程页右上角「写日历」**：连上个人（自建）CalDAV 后出现，直接新建并同步；
  没连时按钮不显示，避免误点；
- 设置 → 常规 → 插件 → 个人日历 → 新建或编辑日程；
- 待办页里日历行的铅笔图标；
- 编辑窗口是独立的 `个人日历日程` 窗口，保存后会自动刷新。

## 本机验证

`write.rs` 的单元测试覆盖：修改时保留未编辑字段与嵌套提醒、重复日程拒绝、
新建生成的 UID、凭据不跨来源。连接真实服务器时建议先在测试日历上验收，
插件只会在确认写入成功后刷新列表。
