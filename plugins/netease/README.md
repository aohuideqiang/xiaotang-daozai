# 网易云音乐适配

上游只读取普通安装版的日志，也没有进度跳转；插件补上这两点，其他播放、歌词、
封面和本地控制逻辑继续沿用上游。

## 商店版日志目录

网易云商店版（微软商店安装）把播放日志和队列放在包隔离目录：

```
%LOCALAPPDATA%\Packages\<包族名>\LocalCache\Local\NetEase\CloudMusic\cloudmusic.elog
```

`paths.rs` 只向系统查询**正在运行的那个播放器进程**的包族名，不扫描其他应用：

- 商店版目录里有日志时优先用它；
- 没有日志（比如刚安装）时回退普通安装版 `%LOCALAPPDATA%\NetEase\CloudMusic`。

`netease_playback` 的读取器会记住当前文件；日志目录从普通版换到商店版时清空旧偏移
和播放状态，不会把上一份日志的进度带过来。

## 进度跳转

网易云 3.x 的底部播放条由 CEF 渲染，既没有系统 seek 接口，也没有 UIA 控件。
`seek.rs` 的做法：

1. 用本地日志取当前歌曲和时长；
2. 找到播放器窗口里的渲染控件（`Chrome_RenderWidgetHostHWND` / `Chrome_WidgetWin_0`），
   把目标时间换算成播放条上的坐标，直接发鼠标消息；
3. 窗口最小化时先把窗口临时透明还原（不激活、不抢前台），点击后恢复透明度和最小化；
4. 每 100 ms 回读日志位置，确认到达才报告成功。

跳转失败时岛体会提示「未能确认跳转，请在播放器内调整进度」。

## 没有移植的部分

二开曾在 `netease_timeline` 里额外接受一个网易云构建时间戳（`0x6aca354c`）。上游现在
用日志读取原生进度作为主路径，插件也只用日志回读，所以没有再加第二个偏移，避免依赖
特定客户端版本。

## 验证

- 单元测试：商店版目录优先、回退普通目录（`paths.rs`）。
- 手工验证：启动网易云并播放一首歌，在岛体音乐页点进度条；期间最小化播放器也能跳转。
