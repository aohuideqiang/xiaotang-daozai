# 岛体交互

## 两侧滚轮翻页

`edge_wheel` 只认岛体左右各 36 像素的窄条：

- 向下滚 → 下一页，向上滚 → 上一页；
- 高精度滚轮按累计量翻页，连续滚动有 0.20 秒的最小间隔，不会一次跳过几页；
- 停手或反向时丢弃半格余量。

中间区域**不改变**上游行为：列表能滚就滚，滚不动时由上游决定是否翻页。这样上游的
滚轮回归测试（`src/ui_tests.rs` 里的 `wheel_*`）继续有效，跟上游合并时不需要改测试。

## 左右滑切

`swipe` 在面板主体上观察按下和抬起：

- 在内容区横向拖动超过 55 像素、且横向明显大于纵向时翻页；
- 音乐页的进度条区域整块排除：按在进度条上拖动是跳转，不是切页，否则松手会先翻页，
  这一帧不再画音乐页，跳转命令也就发不出去。

## 验证

`plugins/island_gestures/mod.rs` 的单元测试覆盖进度条排除和切页区域判断；上游
`ui_tests` 的滚轮测试全部保留通过。
