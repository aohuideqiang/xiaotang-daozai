# 桌面工具

一个独立窗口，装常驻在岛体之外的小工具。做成独立窗口而不是岛体页面，是为了不碰
上游固定的页面数组（`PAGE_NAMES`、`visible_pages`、`page_order`），跟着上游更新时
不需要改这些地方。

## 入口

- 设置 → 常规 → 插件 → 桌面工具；
- 拖一个 http/https 链接到岛体上，会直接打开下载页并开始下载。

## 功能

| 分页 | 内容 |
| --- | --- |
| 课表 | 两日预览 / 完整一周，支持上一周、今天、下一周，按学期周次和节假日排课 |
| 下载 | Edge 正在下载的文件 + 岛仔自己的下载任务（最多同时 3 个，写到 `Downloads`） |
| 快捷启动 | 名称 + 应用路径或网址，最多 50 个，点击直接打开 |
| 系统性能 | CPU 与内存占用，每 2 秒采样 |
| 服务器任务 | 通过 SSH 读取服务器容器与 systemd 状态，每 30 秒刷新 |
| 设置 | 开关、独立课表文件、服务器 SSH 连接参数 |

剪贴板历史没有再做一份：上游置物架已经有「剪贴板」分栏（文字、固定、排除密码内容），
插件不再重复采集。

## 文件

都在用户数据目录 `%APPDATA%/Daozai`（可用 `DAOZAI_DATA_DIR` 覆盖）：

| 文件 | 用途 |
| --- | --- |
| `desktop-tools.json` | 开关、快捷入口、课表路径、SSH 参数 |
| `server-connection.json` | 由插件按 SSH 参数生成，`server-overview.py` 只读它 |
| `server-overview.py` | 插件内置脚本的副本；用户自定义过路径时不覆盖 |
| `courses.json` | 独立课表（可以放到别处，在设置里指路径） |

旧的五开关配置（第一项是剪贴板）会自动迁移到现在的四项。

## 独立课表 JSON

```json
{
  "term_start": "2026-09-07",
  "term_end": "2027-01-17",
  "holidays": ["2026-09-14"],
  "rules": [
    { "weekday": 1, "weeks": [1, 2, 3], "start": "08:10", "periods": "1-2节",
      "course": "高等数学", "location": "A301", "teacher": "李老师" }
  ]
}
```

`weekday` 1 是周一，`weeks` 是学期周次；节假日整天不排课；超出学期范围也不排课。

## 服务器任务

`runtime/server-overview.py` 通过 SSH 标准输入在远端执行一段只读脚本，远端不落文件：

- `docker ps` 判断容器是否运行、是否 unhealthy；
- `systemctl show` 判断 systemd 服务/定时器状态；
- 连不上时仍然列出全部条目，逐项标记「连接失败」，并在表头显示原因。

服务清单在脚本里（近端和远端的 `CATALOG`/`SERVICES` 保持同步），改清单时两处一起改。

## 拖放

`drop.rs` 注册自己的 OLE 拖放目标，替换窗口库原来的目标：

- 链接（`UniformResourceLocatorW` / 文本里的 http(s) 地址）→ 下载页并开始下载；
- 文件（`CF_HDROP`）→ 交给 `App::on_drop`，和上游一样放进置物架。

注意：窗口库原来的拖放目标被替换后，岛体「把文件拖到这里」的高亮提示不会再出现，但文件仍然会进置物架。

## 验证

单元测试覆盖课表周次/节假日、配置迁移；采样线程与窗口在真实桌面上手工验收。
